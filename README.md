# 🎨 Laboratório de CSS – Do Básico ao “Uau”

Projeto prático criado para treinar **CSS na prática**, explorando desde conceitos básicos até recursos modernos como Flexbox, Grid, responsividade e animações.

> O foco principal é o CSS. O HTML foi usado apenas como estrutura de apoio.

---

## 🚀 Demonstração

Interface com:

* Layout moderno em Grid e Flexbox
* Cards responsivos
* Formulário estilizado
* Tabela personalizada
* Menu fixo com efeito glassmorphism
* Responsividade para mobile

---

## 🧠 Conceitos de CSS praticados

* Box Model (margin, padding, border)
* Flexbox (alinhamento e organização)
* CSS Grid (layout em colunas)
* Pseudo-classes (`:hover`, `:focus`)
* Position (`sticky` e `fixed`)
* Variáveis CSS (`:root`)
* Responsividade com Media Queries
* Transitions e efeitos visuais
